# Lab 1: Bouncing Ball

A beginner Pygame project created for my A.I. for Game Programming class.

This project simulates over 1,000 balls moving around the screen. The balls interact with each another through gravitational forces and bounce off each other when they collide.

## Features
- Over 1,000 moving balls
- Gravitational forces between balls
- Elastic collisions
- Gravity and friction
- Screen boundaries
